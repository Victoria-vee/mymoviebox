# mymoviebox
🎬 Movie Ranker

A web application that allows users to rank, compare, and organize movies based on personal preference. The project focuses on clean UI, intuitive ranking logic, and solid frontend/backend integration.

📌 Features
Users can:
-Add movies to a personal list

-Add what they'll rate the movies

-Type in what the thought about it

-movies would be viewed in other of addition

-Simple and user-friendly interface
